1. Confirm this is the private repository named
   `rtt-developer-supply-chain-2026`.
2. Clone it over HTTPS and open the folder in Visual Studio Code.
3. Trust only this assigned exercise workspace when VS Code prompts.
4. Accept the workspace recommendation for `rtt-labs.dependency-insights`.
5. In the VS Code terminal, run:

   ```powershell
   npm install
   npm run build
   ```
